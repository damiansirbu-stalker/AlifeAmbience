================================================================================
  ALIFEAMBIENCE
  A dark-mood ambient overlay for S.T.A.L.K.E.R. Anomaly / G.A.M.M.A.
================================================================================

AlifeAmbience layers the Zone's dark side over your existing ambience. It gathers
the dreadful, horror, and mournful sounds from several soundscape packs, keeps the
best-quality copy of each, and composes them on top of whatever ambient mod you
run. It does not replace your soundscape; it adds to it through DLTX, so it works
alongside GAMMA's ambience, vanilla, or any other soundscape.

The goal is immersion and variety, not raw volume. Dread here comes from distance,
rarity, and surprise: a far-off scream landing in near-silence, not a wall of
constant noise.

What it adds
------------
- Dread: distant mutant growls, far-off screams, spooks, dark ambience, the dark-signal cue.
- Underground horror: the full tunnel and lab set. Whispers, rats, banging, metal groans, drips.
- Tension: distant gunfire, ominous drones, creeping wind, branch creaks.
- Eerie atmosphere: owls, distant dogs, crows, fog.
- Oppressive weather: storms, rain, howling wind.

What it does NOT touch
----------------------
- Generic daytime life (birdsong, insects, plain wind, pleasant tree/foliage). Your base ambience keeps providing those.
- Emission and psi-storm sound. Left to their own systems.

How it works
------------
A DLTX overlay adds and fills the dark channels and switches them on per map and
time, without overwriting the base ambient files. It can load at any position.

How it is built (the method)
----------------------------
AlifeAmbience is generated by a tool from the source packs, not hand-assembled,
and it holds to a set of measured rules:

- Curated, not dumped. Each source pack already sorts every sound into a channel; that assignment is the curation. The tool reuses it and keeps only the dark, dreadful, and mournful channels.
- Deduplicated by content. Identical files that several packs reship collapse to one copy by exact content hash, so nothing is stored twice, while genuinely different sounds are always kept.
- Quality-gated. Only 44.1 kHz OGG is kept (the Anomaly standard); off-spec and junk-bitrate files are dropped.
- Soft and rare by construction. Distances and firing rates are set to the softest and rarest values any source pack uses, then held to an absolute floor so the result is calmer than vanilla, not just calmer than the loudest pack.
- Density-capped to vanilla's own limit. The number of sounds that can play at one place is never allowed above vanilla Anomaly's own maximum (13 channels; vanilla averages about 10). We measured every source to set this; nothing plays busier than the base game already does.
- Variety without bloat. A single channel can hold many sounds for variety (that is free; one is picked at random each time), while the number of simultaneous channels stays capped. When more variety is added, same-role sounds are merged into one channel instead of adding another parallel layer.

The build is reproducible: point the tool at the packs, run it, and it
regenerates the whole overlay, so adopting a new pack or sound is a re-run, not a
rewrite.

Options (MCM)
-------------
An optional "Announce ambient sounds" diagnostic, off by default, prints each
ambient sound that plays (its channel, file, distance, and volume) to the screen
as a PDA tip and/or to a log file. It is there to show exactly what the Zone is
playing around you; leave it off for normal play.

Installation
------------
Mostly content and configuration, delivered as a DLTX overlay, plus one optional
diagnostic script controlled from MCM (off by default; the mod does nothing extra
while it is off). As a DLTX overlay it can load at any position. Requires 44.1 kHz
OGG playback (the Anomaly standard), and xlibs for the optional announce feature.
